# Evidence manifest

## Qualifying evidence

`npm run discover` writes a genuine model-driven run to `evidence/discovery/` and replaces the saved capability in `evidence/artifacts/`. Run it before submission with either `ANTHROPIC_API_KEY` or `OPENAI_API_KEY` configured.

`npm run replay` writes model-free production-path runs to `evidence/replay/`. The final submission should contain:

- one successful replay with a different member input,
- one `MEMBER_NOT_FOUND` business outcome,
- one human-handoff or hard-failure example.

## Offline smoke evidence

`evidence/runtime/` is generated by `npm run demo`. Its discovery event identifies the model as `scripted:offline-nonqualifying`. It exists so reviewers can verify the complete local wiring without API access. It must not be confused with the qualifying LLM discovery run.

All evidence is synthetic. Logs redact member identifiers and sensitive output values. Screenshots mask input values, member-profile values, and balances.
